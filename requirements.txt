# 公文汇编助手 —— 运行依赖（全部精确锁定）
#
# 为什么锁死版本：v1.2.1 发布时 requirements 写的是 PySide6>=6.6，
# 之后 PySide6 6.8+ 收紧了枚举访问规则，代码里 `dlg.Accepted` 这种实例级
# 写法开始抛 AttributeError —— 用户一启用启动口令锁，程序就启动即崩。
# 也就是说同一份源码、同一条 CI 流水线，在不同日期构建出的安装包行为不同，
# 且没有任何环节会报警。锁定版本是让"构建产物可复现"的前提。
#
# 两处必须分档，不能一刀切：
#   1) PySide6 分平台：Linux/麒麟 必须停在 6.8.0.2，官方 aarch64 wheel 自
#      6.8.1 起要求 glibc>=2.39，麒麟全系（glibc 2.31）不满足。
#   2) 部分包分 Python 版本：麒麟 CI 在 Debian 11 容器内用 Python 3.9 构建
#      （为守住 glibc 2.31 底线不能升级容器），而这些包的新版已放弃 3.9。
