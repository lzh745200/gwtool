### 2.1 重复字规则：12 处误报，全部是"合法重复"

| 命中 | 上下文 | 为什么合法 | 守卫 |
|---|---|---|---|
| `批批` | 一批批官兵重走长征路 | 量词叠用表周遍 | `一 + X + XX` 判据 |
| `买买` | 买买提江·吾买尔 | 少数民族人名 | jieba token 覆盖 |
| `师师` | 红34师师长陈树湘 | `师` + `师长` 跨词 | token 覆盖（`师师长`） |
| `团团` | 第100团团长韩伟 | `团` + `团长` 跨词 | token 覆盖（`团团长`） |
| `京京` | 韩京京 | 人名 | token 覆盖（`韩京京`） |
| `猎猎` | 红旗猎猎 | 文学叠词 | jieba 认定为一个词 |
| `权权` | 权权交易、权钱交易 | 政治术语 | jieba 词 + 固定搭配白名单 |
| `场场`/`簇簇`/`段段` | 一场场殊死搏杀 / 一簇簇火种 / 段段接力推进 | 量词叠用 | `一+X+XX` 判据 |
| `对对` | 对标对表、校准偏差 | 固定短语 | 固定搭配白名单 |

设计原则：**只用确定性信号**（jieba token 区间、词是否为完整 token、`一+X+XX` 结构、极少固定搭配），
不做语义猜测；真正的多打一字（`的的`、`了了`、`我我`、`进行行`）两侧都是独立 token，仍照报。

### 2.2 低置信生成对：3 处 `还誓 → 还是`

上下文 `截掉伤腿还誓要爬到陕北`（`还` 副词 + `誓` 动词）。修法：低置信（<0.7）生成对命中，
**首字是常用虚词/副词**（还/也/就/都/又/才/只/已/正/在/再/更/最/很/太/挺/蛮/真/可/却/倒/竟/偏/宁/仍/尚/且）→ 抑制。
E2 未受影响（80.6% 持平）。

> 这个虚词集合是**按 E2 实测代价筛过的**：把副词表全收时 E2 掉到 638/800 = 79.8%（−7），
> 逐字归因发现代价全在 `却/可/只/太/就` 五字（`却嗜→却是`、`可揖→可以`、`只妖→只要`、
> `太样→太阳`、`就湿→就是` 都是**真实错形**），排除后回到 80.6%，`还誓` 仍被抑制。

> 另一个实现坑：jieba 的 HMM 会把**孤立输入**里的任意同字连并成一个 token（`我我`、`及及` 都并），
> 所以"连本身成词"守卫必须排除虚词与人称代词，且**只对两字连生效**——否则 `哈哈哈`
> 的拟声判定会被吞掉。这两点在测试里都有反例钉住。

## 四、边界与后续

1. **样本量仍偏小**：35 篇 / 9 万字，0.11 处/万字的置信区间仍然偏宽；要形成稳定门禁，建议累计到
   80–100 篇（公开政府文本可继续扩，军报/求是受授权与站点结构限制）。
2. **重复字规则仍有残余风险**：人名/地名中的叠字（如"京京"）靠 jieba token 覆盖识别，
   超出词典的名字仍可能漏过；后续可引入用户自定义人名表（设置项）。
3. 语料与授权文件不入库；如需入库，须提供正式审批编号后按批 `git add -f`。
