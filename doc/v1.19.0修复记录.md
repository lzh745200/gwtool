### 误报治理（真实语料逐条 triage）
开发中在 220 篇真实语料上发现并修掉 5 类误报：
1. 「之所以…**是因为**/**正是因为**/**恰恰因为**」是正确写法 → 加负向先行断言；
2. 「不但…**反而**」是合法对比 → 删除该规则；
3. 「只有**一个**…就是」列举句 → 列举守卫扩展到 v2 整段命中；
4. 「充分彰显…**作为**重要组成部分」被「分…为…组成」跨词误配 → 改为字面「分为…组成」；
5. 「大约/近/至少/超过…左右/以上」跨句误配 → 限定为数字量词紧跟。

## 二、一致性校验补全（`gwtool/core/consistency.py`）

新增两类（只提示、不产生替换文本）：
- **一级序号跳号**：行首「一、二、四」跳过「三、」；序号变小视为重新起编，不误报；
- **日期区间倒序**：「2026年10月至2025年3月」；支持同年简写「2026年10月1日至10月7日」。

## 五、边界

1. 病句集为项目自建（六类各 20 句），召回是"规则自覆盖"而非独立第三方基准；
2. 语序类召回 75%，"关于…的问题/状语后置"等仍以提示为主，未强行自动改；
3. 一致性新增两类只提示；"指代不明/机构简称混用"仍不在本版范围（误报风险高）；
4. 规则 v2 与旧 grammar_rules 存在少量同义规则，靠 `_dedupe` 去重，未做合并重构。
