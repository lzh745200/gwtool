## 二、代码修复

### 2.1 前后端契约
1. **参考面板 severity 口径不一致**（`ui/reference_panel.py`）：原先按
   `confidence >= 0.8` 二分显示"确认错误/疑似错误"，与 v1.17 后端三级
   `severity`、与「任意文档纠错」界面互相矛盾。改为统一读 `c.severity`
   （error/warning/suggest → 错误/待确认/提示），颜色与底色同步。
2. **增强包开关持久化失败不可见**（`ui/feature_dialogs.py`）：导入/卸载时
   `set_setting()` 失败只写日志，界面仍报"成功"。改为在结果提示里明确
   "包已就位，但自动开启/关闭未保存，请手动勾选/取消"。
3. **目录深度无 UI 入口且提示与默认值不符**（`ui/template_editor.py`）：
   新增「目录层级」下拉（1/2/3 级，默认 2），加载/保存接入 `toc_max_level`；
   提示文案改为"默认 2 级（材料标题 + 一、）"。
4. **UI 跨层调用私有 API**：`feature_dialogs` 从 `core.importer` 导入
   `_text_to_tree`。新增公开 `importer.text_to_tree()` 并改调用，行为不变。
5. **「输出预览」页永远空白（接线丢失）**：`EditorPanel.show_pdf()` 及其
   渲染链一直存在但无调用方。`open_compile_wizard()` 在向导生成 A4 后补上
   唯一缺失的接线：渲染成品 PDF 到「输出预览」页。

## 六、边界（收口不等于无限承诺）

   但"输出预览像素级效果"仍需真机肉眼确认一次。
