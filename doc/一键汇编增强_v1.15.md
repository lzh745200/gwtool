# 一键汇编增强（v1.15.0）操作说明

> 入口：主窗口工具栏「一键汇编」、菜单「文件 → 一键汇编…」或快捷键 **Ctrl+N**。
> 三步向导：**选材料 → 定模板与封面 → 出成品**。全程离线，不依赖 Word/WPS/Office。

本次增强把"汇编成一套正式公文"需要的选项都放进了向导，并给出**默认可用**的安全值：
默认生成 DOCX、生成封面、生成目录、生成页码；A3 骑马钉由 A4 拼版，勾选时自动补勾 A4。

---

## 1. 第 1 步：选材料

- 勾选要汇编的材料；拖动或用「上移/下移」调整顺序，汇编按列表顺序合并。
- 支持分类/标签筛选；「全选/全不选/反选」只作用于**当前筛选出的**材料。
- **识别结果**：每条材料后面会显示

  `识别：标题 1 · 一级 2 · 二级 3 · 正文 18`

  分别表示：文档标题块、一级标题块、二级标题块、正文块的个数。
  用于快速判断"这篇材料的层级结构是否被正确解析"。
- 材料没有块结构（纯文本导入/旧数据）时，自动按简单统计兜底，不影响选择与生成。
- 已有「将每份材料的标题作为一级标题」选项，默认勾选。

---

## 2. 第 2 步：字体方案与封面

### 2.1 字体方案

| 方案 | 说明 |
|---|---|
| 标准公文（GB/T 9704） | 使用当前「模板」下拉框选中的模板（默认即标准公文模板） |
| 军队公文（GJB 5100A） | 使用内置军队公文版式；与 GB/T 9704 的页面参数一致（A4、版心 156×225mm、22 行×28 字），差异在文种与要素编排 |
| 自定义模板 | 使用「模板」下拉框里保存的自定义模板（与旧版行为一致） |

模板下拉框**始终可用**（保持原有操作方式）；点「打开模板管理…」可编辑字体/字号/
行距/页边距。

字体方案下方会列出当前模板实际会用的字体：

```
字体方案：封面标题 方正小标宋简体；一级标题 黑体；二级标题 楷体_GB2312；
三级标题 仿宋_GB2312；正文 仿宋_GB2312；页码 宋体
✓ 本机字体齐全
```

若本机缺少某个字体，会显示：

```
⚠ 本机缺少：方正小标宋简体、楷体_GB2312（Word/WPS 会用替代字体，字宽与行距可能偏差）
```

这时生成的 DOCX 仍可打开，但 Word/WPS 会静默替换字体，**版心 22 行×28 字可能不成立**。
建议安装对应公文字体后重新生成；PDF 由内置渲染器生成，会走字体回退链，不受 Word 字体影响。

### 2.2 封面字段

| 字段 | 默认 | 说明 |
|---|---|---|
| 生成封面页 | **开** | 关闭则产物不生成封面 |
| 汇编名（封面标题） | 空 | 同时作为默认输出文件名与台账登记标题 |
| 副标题 | 空 | 留空则不显示副标题行 |
| 单位名称 | 空 | 留空则不显示单位行 |
| 封面日期 | **今天** | 可清空；清空则封面不显示日期行 |
| 文种/密级/紧急程度/发文字号 | 空 | 只写入封面与发文台账，参与台账登记 |

**留空行为与旧版一致**：空字段在 DOCX/PDF 渲染时被直接跳过，不会产生空行、不会
让版面异常，也不会崩溃。全部留空且勾选「生成封面页」时，封面只保留标题回退
（模板名称）等必要元素。

---

## 3. 目录与页码（第 2 步）

| 选项 | 默认 | 说明 |
|---|---|---|
| 生成目录 | **开** | 自动收集各级标题；关闭则产物没有目录页 |
| 目录标题 | `目  录` | 可改为「目录」「目 录」等 |
| 生成页码 | **开** | PDF 奇数页右侧、偶数页左侧（外侧） |
| 正文页码从 1 | 固定说明 | 封面与目录页不计入正文页码；正文从第 1 页开始编号 |

> 说明：DOCX 的页码由 Word/WPS 打开后按页脚域显示；PDF 由内置渲染器直接盖页码。
> 如果在本机看不到页码，检查「生成页码」是否被关闭，或模板的页码字体是否缺失。

---

## 4. 第 3 步：输出

### 4.1 输出格式

| 勾选 | 产物 | 说明 |
|---|---|---|
| 「规范 Word 文档（.docx）」 | `<文件名>.docx` | 可继续编辑、打印，WPS 兼容 |
| 「A4 PDF」 | `<文件名>.pdf` | 内置渲染器，含目录、页码，固定版式 |
| 「A3 横向小册子 PDF」 | `<文件名>_小册子A3.pdf` | A4 双面打印后对折成 A3 骑马钉小册子 |

- 三个钩子可**独立勾选**；**勾 A3 会自动补勾 A4**（A3 由 A4 拼版，硬依赖）。
- 至少勾选一种输出，否则不会开始生成，并在向导底部提示"请至少勾选一种输出"。

### 4.2 文件名与输出目录

- 「输出目录」：默认是系统「文档/公文汇编输出」目录；点「选择目录…」可更换。
- 「文件名」：不含扩展名；默认用「汇编名」，汇编名也留空时用「汇编成果」。
- 这两项在生成前就能看到最终路径预览：
  `将输出到：<目录>/<文件名>.docx / .pdf`
- **同名文件已存在**时，本次输出自动追加时间戳（如 `汇编成果_20261024_153012.docx`），
  不会静默覆盖旧文件；此时会弹一次非阻塞提示告知改名（发生在生成之前）。
- 标题/文件名里的 `\ / : * ? " < > |` 会被自动清洗，避免 Windows 生成失败。

### 4.3 其他选项

- 「附汇编材料来源清单」：默认开；在成稿末尾附一张表，列出每份材料的标题、
  原文件名、导入时间与分类，便于追溯归档。
- 「批量模式：每份材料单独生成一份规范公文」：保持旧版行为 —— 按第 1 步顺序逐份
  生成 DOCX 到 `<输出目录>/<批量汇编名>/` 下，每份材料独立成文，不生成 PDF/小册子。

## 5. 健壮性与失败提示

- **空选择**：未勾任何材料时点「开始生成」，向导底部显示
  「请先在第1步勾选材料，再开始生成。」，不会启动任务、不弹模态框。
- **没有勾选输出**：显示「请至少勾选一种输出…」，不会启动任务。
- **单份材料 / 无标题材料 / 10 万字长材料**：均可生成；无标题时文件名与封面回退为
  「汇编成果」；超长材料在后台线程生成，界面不冻结。
- **生成中**：「开始生成」按钮置灰、进度条显示为忙碌状态，防止重复点击；
  完成/失败后自动恢复。
- **失败**：底部状态区显示中文原因（如「生成失败：…」），**不弹模态框**；
  已生成的产物保留在输出目录，可按提示手工处理。
- 批量模式：逐份生成并汇总"成功 N 份/失败 M 份"，不逐份弹框；可中途停止
  （当前正在生成的那一份完成后停止）。

## 6. 常见问题

**Q：字体提示"本机缺少…"怎么办？**
A：安装对应公文字体（方正小标宋简体、仿宋_GB2312、楷体_GB2312、黑体等）后重新
生成；DOCX 的字体会被 Word/WPS 替换，PDF 由内置渲染器回退，两种产物的字形可能不同。

**Q：勾了 A3 小册子，为什么 A4 PDF 也自动勾上了？**
A：A3 骑马钉是把 A4 双面打印后对折拼版，必须先有 A4 PDF。取消 A3 后 A4 仍会保留，
可手动取消。

**Q：目录标题改了但产物没变化？**
A：目录标题只影响**目录页顶部文字**；如果关闭了「生成目录」，自然不会出现。
生成后请用 Word/WPS 打开 DOCX，按提示更新目录域（或直接使用 PDF）。

**Q：封面字段全部留空会怎样？**
A：与旧版一致：空字段被跳过，不会出现空行或异常；封面标题回退为模板名称。
如果不需要封面，直接取消「生成封面页」即可。

**Q：输出目录/文件名在哪里改？**
A：第 3 步顶部：目录可点「选择目录…」，文件名可直接编辑；下方实时显示最终路径。

**Q：两套字体方案有什么区别？**
A：标准公文（GB/T 9704）与军队公文（GJB 5100A）的页面参数与字体要求一致，
本产品默认模板同时满足两套标准；差异主要在文种与要素编排（见「新建公文」的文种骨架）。
选择方案只影响使用的模板，不会改变已填写的内容。

---

## 7. 数据与隐私

- 汇编只读取本机资料库/所选文件，全程零网络。
- 产物写入你指定的输出目录；不会上传、不会自动外发。
- 产物可选择存入资料库（带「汇编成果」标签），也可只在输出目录留文件。
- 失败与异常只写界面状态与本地运行日志，不上报任何内容。
