# v1.15.0 修复记录（一键汇编增强）

> 基线 v1.14.0。按 doublecheck 六维契约（本会话 `doublecheck_spec`）交付：
> 任意**文本类**文档（TXT/MD/DOCX/DOC/PDF 文本层/HTML）导入后，一键汇编产出规范汇编件：
> 封面、目录（页码准确）、正文页码从 1、标题/各级标题/正文字体分层，可按需导出 A4 与 A3 骑马钉。
> 扫描件 OCR、PDF 表格/分栏还原、打印驱动改造属非目标。

## 一、交付内容

| 能力 | 实现 |
|---|---|
| 任意文档规范化 | 新增 `gwtool/core/compile_norm.py`：markdown 标记剥离、首行文种标题识别、`一、/（一）/1.` 层级识别（行首且 ≤60 字才判标题）、主送/落款识别、硬换行续接；接入 `compiler.load_trees`，纯文本/markdown/PDF 提取文本都能得到可排版结构 |
| 封面 | `docxgen` 封面默认启用（单位/汇编名/副标题/日期）；`template.cover_visible()` 保证"字段全空不出空页"；PDF 渲染器新增封面页（此前 PDF 第 1 页直接是目录） |
| 目录 | **层级可配，默认二级**（`toc_max_level=2`，避免 30 条 `1.` 枚举把目录撑成 3 页）；DOCX 目录域同步 `\o "1-2"`；PDF 目录页码写**正文纸面页码**，与实际一致 |
| 页码 | 封面/目录不编号，正文从"— 1 —"连续；DOCX 用分节 + `<w:pgNumType w:start="1"/>`（WPS 真机验证一致）；PDF 侧 `stamp_page_numbers(skip_pages=前置页数)`，奇右偶左外侧 |
| 字体分层 | 标题 方正小标宋简体 22pt 居中、一级 黑体 16、二级 楷体_GB2312 16、三级 仿宋_GB2312 16 加粗、正文 仿宋_GB2312 16；DOCX run 级 `w:rFonts@eastAsia` 与 PDF 字体链同源 |
| 层级重定基 | 材料标题以一级插入时，材料内部标题整体 +1（封顶 3）；DOCX 与 PDF 走同一 `load_trees(insert_material_titles=True)`，目录层级逐项一致（此前 PDF 路径漏做，二者不一致） |
| A3 骑马钉 | A4 导出 → A3 横向 1190.55×841.89pt 2-up；页数补齐 4 的倍数、页序 `[n,1][2,n-1]…`、装订边 6pt + 安全边 2pt、`imposition_plan()` 页数→印张推导、`make_booklet_pair()` 双产物 |
| 向导 | DOCX/A4/A3 三钩子（勾 A3 自动勾 A4）、输出目录/文件名/路径预览、封面字段（含副标题）、目录/页码开关与目录标题、字体方案与缺字体提示、材料识别统计、空选择/失败中文非模态提示、生成中禁用按钮 |
| 跨页重影根治 | PDF 渲染由"整篇 translate + ctx.clip"改为 `QTextDocument.drawContents(rect)` 逐页裁剪；另保留封面/目录表 frame 的兜底清理（表格 frame 不受 drawContents 裁剪） |

## 二、实测（本机样例，`doc/示例/一键汇编样例/`）

3 组输入（纯文本通知 / Markdown 意见 / DOCX 多级标题）汇编后：

| 项 | 实测 |
|---|---|
| 材料份数 | 3 |
| A4 页数 / 尺寸 | 6 页 / 595×842pt |
| 页面构成 | p1 封面（无页码）→ p2 目录（无页码）→ p3–p6 正文（—1—…—4—） |
| A3 页数 / 尺寸 | 4 页 / 1191×842pt（偶数页，2-up） |
| 目录 | 默认二级，条目页码与正文纸面页码一致 |
| 字体（DOCX run） | 方正小标宋简体 / 黑体 / 楷体_GB2312 / 仿宋_GB2312 均出现 |
| 跨页重影 | 逐页版心以下窄带仅页码，无下一页首行 |

验收矩阵（`scripts/compile_matrix.py`）：5 类输入 × DOCX/A4/A3，最终完整档 **PASS 124 / FAIL 0 / SKIP 16**（快速档 PASS 24 / SKIP 4）；SKIP 均为"离线无法更新 DOCX 目录域"和"本机缺公文标准字体无法判定 PDF 字体族"，均带原因，不冒充 PASS。字体抽样按公文序号定位：材料标题 方正小标宋简体 / 一、黑体 / （一）楷体_GB2312 / 1. 仿宋_GB2312 加粗 —— 全部 PASS。

## 三、本版修掉的缺陷

1. **封面页混入目录标题 / 跨页重影**：根因是 `ctx.clip` 不阻止落笔，下一页首行画进上一页底部；改为 `drawContents(page_rect)` 逐页裁剪，封面/表格 frame 再走页级 redaction 兜底；两遍渲染都清理。
2. **`_PAGE_BREAK` 未定义**（重构中间态）：render 时 NameError；补模块级常量并加断言。
3. **PDF 路径未做材料层级重定基**：DOCX 目录层级 1/2/3、PDF 扁平为 1/1/2；统一到 `load_trees_ex(insert_material_titles=…)` 单一事实源。
4. **`doc_title` 字段未进 `from_json/clone`**：批量汇编每篇 clone 后退化成 dict → AttributeError 整批失败。
5. **目录被三级枚举淹没**：默认 `toc_max_level=2`，可配 3。
6. **封面默认关闭**：`default_template()` 打开封面，`cover_visible()` 保证空字段不产生空白页。

## 五、已知边界

1. DOCX 的目录是 Word 域，**离线无法自动更新页码**（打开 Word/WPS 时按提示更新）；PDF 侧目录页码由内置渲染器两遍渲染计算，已验证一致。
2. 本机缺少公文标准字体时，DOCX/PDF 会回退字体并给出缺字体提示；验收矩阵中"PDF 字体族"项标 SKIP。
3. 扫描件 OCR、加密/损坏文件：按非目标处理，单文件失败有中文原因且不拖垮整批。
