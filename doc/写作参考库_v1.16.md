# 写作参考库（v1.16）

> 目标：把「公版 / 开放授权」写作语料接进 gwtool，让写作时能**检索—对照—仿写**，
> 而不是凭感觉堆词。语料包只读、离线，不写入资料库、不联网。

## 一、语料包（2026-10-25 版）

| 指标 | 数值 |
|---|---|
| 文档 | **655 篇**（政府公开文件 35 + 公版古籍 620） |
| 正文 | **1,198,053 汉字** |
| 结构化标注 | **60,801 句**（论点/论据/过渡/结尾/背景/其他 + rule + conf） |
| 模板 | **354 条**（模板库.md；程序加载其中精选 201 条） |

包含古籍：贾谊新书、论衡、潜夫论、盐铁论、商君书、中论、中说、何博士备论、说苑、
读通鉴论、战国策、曾国藩家书。政府文件来自中国政府网公开发布的政策文件。

来源与授权：
- 古籍原文为**公有领域**，整理数据来自 [NiuTrans/Classical-Modern](https://github.com/NiuTrans/Classical-Modern)（MIT）；
- 政府文件为**官方公开文件**，依《著作权法》第五条不适用著作权；
- 语料包仅供个人学习与内部写作参考，不对外分发。

## 二、在 gwtool 里怎么用

菜单 **工具 → 写作参考库…**：

1. 默认自动加载 Downloads 下的 `写作语料库_公版_*`（目录或 zip），也可"浏览…"选其它包；
2. 输入关键词（如"表率""监督""数据"）检索；角色筛选可选 **全部 / 论点 / 论据 / 过渡 / 结尾 / 模板**；
3. 选中条目可在右侧查看来源、角色、规则与置信度；双击或"插入到正文"把句子插到光标处，"复制选中"进剪贴板；
4. "模板"页签列出高频句式骨架（如 `故{主体}之事 不可不察也`），用于仿写结构而非照抄。

## 四、标注口径（重要）

- **规则式标注，不是人工/模型标注**：每条句子带 `rule`（命中规则）与 `conf`（0–1）；
  准确率随文体波动（政府文件与论说文较高，叙事类偏低），模板务必人工复核后使用。
- 模板是**句法骨架**：数字/年份/比例/引文/主体已替换为槽位（{数字} {年份} {主体} {引文}），
  原文例句一并保留，便于对照。
- 语料包由外部构建脚本生成（`构建标注.py`），不在产品运行时内；产品只读加载。

## 五、边界

1. 检索是**子串匹配**（不区分大小写），不做分词/语义检索；
2. 语料包不含维基文库、ctext、国家法律法规数据库等（抓取条款/验证码/网络限制，详见包内 README）；
3. 模板库是"可仿写"提示，不保证适用于所有文种；出现规则误判时以例句为准。
