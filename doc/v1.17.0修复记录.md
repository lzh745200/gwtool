# v1.17.0 修复记录（校对可信度 P0：分级 / 受保护 / 撤销 / F0.5）

> 基线 v1.16.0。本批按 doublecheck 六维契约落地 P0：**三级置信门控**、
> **受保护片段**、**每句修改上限**、**E7 配对精确率（F0.5）**、**界面分级/理由/接受此类/撤销**。
> 不引入新依赖、不联网、不改变既有指标。

## 一、引擎（`gwtool/core/corrector.py`）

| 能力 | 规则 |
|---|---|
| `Correction.severity` | `error / warning / suggest`，默认 `error`（历史构造点零改动） |
| **error** | 非提示类、conf ≥ 0.60、不在受保护片段、同句前 2 处 → 可自动写回 |
| **warning** | 同句第 3 处及以后 / conf < 0.60 → 仍列出、需逐条确认 |
| **suggest** | 提示类（数字用法/机构沿革/生成层/表达提示/标点规范）或受保护片段 |
| 受保护片段 | 引号引文、书名号、URL、邮箱、行内代码、数字+单位：只提示不自动改；**标点类例外**（引号内 `...`→`……`、半角括号全角化仍自动改，纯格式归一不改内容） |
| 每句上限 | 同一句自动修改 ≤ 2 处，超出降为 warning，**不丢结果** |
| `correct_block` | 只应用 error；`apply_low_confidence=True` 仅放开「错别字(生成)」，提示标签类永远不放开 |

阈值 0.60 的来源：现有规则层最低置信是"标点"的全角括号归一（0.60）；定 0.70 会把既有标点修复降级（实测回归），故取 0.60 并在此记录。

## 二、评测（`scripts/eval_corrector.py`）

新增 **E7 精标配对精确率**：448 条人工精标对，各构造"错形句 / 正确形句"——

- 错形句必须被**自动层**改对（TP）；漏改计入 FN；
- 正确形句在同一词位**不得有任何自动改动**（FP，红线 0）。

实测（v1.16 语料/引擎）：

| 指标 | 结果 |
|---|---|
| E7 P / R / F0.5 | **1.000 / 1.000 / 1.000**（448/448） |
| 正确形被自动改 | **0 处** |
| E1 / E2 | 448/448 = 100% / 645/800 = 80.6%（未降） |
| E3a | 0.00 处/万字（总口径 58 处提示类 = 1.27） |
| E5 | 14.1 ms/千字（阈值 100） |

门禁：`F0.5 ≥ 0.95` 且 `正确形自动改 = 0`；基准档即参与门禁，退出码 0。

## 三、界面（`gwtool/ui/correct_dialog.py`）

- 列表项按 severity 加前缀与颜色：**【错误】**（可自动）/**【待确认】**/**【提示】**；
- 选中项下方显示**理由 + 类别 + 级别 + 置信度**（此前只显示替换词）；
- 新增 **「接受此类」**：把当前类别里所有错误级命中一次性写回（提示级禁用并说明原因）；
- 新增 **「撤销上次」**：恢复上一次应用前的正文（单步，换文档后清空）；
- 原有「应用此修正 / 全部应用 / 忽略此词 / 导出 DOCX/TXT/报告」路径不变。

## 四、过程中发现并修掉的问题

1. **评测变量遮蔽**（自己引入、自己发现）：E7 构造正确形句时用了局部变量 `neg`，覆盖了语料 `neg` 列表，导致 E3/E5 误报 0 处、E5 假红。已改名 `neg_sent` 并复测恢复（E3a 0.00、E3b 58、E5 14.1）。
2. **标点误保护**：一律保护引号内容会把"引号内省略号/括号全角化"这类既有修复关掉（`test_rules_guard_v19` 两例回归），已按类别豁免标点并复测。
3. **误报阈值回归**：error 阈值最初定 0.70，把 0.60 的全角括号规则降级；改 0.60 后 207 项纠错相关测试全绿。

## 六、边界

1. E7 是**规则层配对精度**，只覆盖 448 精标对所在词位，不代表整体校对准确率；
2. 受保护片段只降低"自动写回级别"，不改变检出（仍以提示呈现）；
3. 每句上限只影响自动应用，超出部分仍出现在列表里；
4. 语法规则库扩容（P1）、一致性扩展、神经增强包不在本批范围。
