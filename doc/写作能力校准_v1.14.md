## 3. 测量方法

`scripts/writing_calibrate.py` 对每篇执行：

1. `kind = writing_hints.detect_kind(text)[0]`（标题/结束语能定文种时取法定文种，否则取 7 文体）；
2. `hints = writing_hints.hints(text, kind)`；
3. 逐条记录 `scope/title/level/detail` + **触发片段**（前置 20 字、命中、后置 20 字）；
4. 汇总：按 title 聚合（次数/篇数）、按 level 分档、每篇密度、每千字密度分布（中位/p90）。

**为什么必须带触发片段**：条数只能看出"吵不吵"，看不出"对不对"。判断
「用语偏空泛：有关」是真该提示还是误报，必须回到原文——只有真实句子能区分
"全篇几十处有关"（偏空泛）与"法规里一次规范引用"（正常）。

产物（`doc/corpus/` 在 `.gitignore` 内，属生成物，不入库）：

## 6. 阈值与逻辑改动清单（每条配真实句子正反例）

> 阈值一律进 `writing_data.py`（数据层），判定逻辑进 `writing_hints.py`；
> 对应正反例全部落在 `tests/test_writing_calibrate_v113.py`（44 条用例）。

### 6.1 「正文分层不明显」加文体门槛（❌175 → 1）

- **落点**：`writing_hints.py:424` `_cohesion_hints(text, kind)`；`hints()` 调用处改为传 kind。
- **依据**：命中 175 篇全部是 junbao(114)/qstheory(61)，gov 18 篇 0 命中。
- **正例**（仍报）：起草阶段未定文种 `kind=""` → 三段落无层级词仍提示。
- **反例**（不报）：`kind="经验材料"` 的媒体文章。
- **残余 1 篇**：军报通讯被 detect_kind 判成"报告"（法定文种）→ 门槛放行，属可接受。

### 6.2 要素审查限定公文文体（❌149 → 2）

- **落点**：`writing_hints.py:386` `_element_hints` 开头 `if kind and not _is_legal_kind(kind): return []`。
- **依据**：要素缺失 149 条几乎全部来自新闻/理论文章（「未识别到日期」123 条）。
- **正例**：`kind="通知"` 的缺要素草稿仍报单位/日期/时限。
- **反例**：`kind="经验材料"` 不再报要素。
- **附带收益**：省掉全文 `extract_slots`（jieba 分词），长文更快。

### 6.3 结束语等价写法 + 公文形态门槛（warn 2 → 0）

- **落点**：`writing_hints.py:328` `_has_closing`、`:347` `_looks_formal`；
  词表 `writing_data.py:168` `CLOSING_ACCEPT`、`:179` `PRINT_NOTICE_MARKS`、`:185` `CLOSING_OPTIONAL_TAIL`。
- **依据**：warn 全部来自两类真实公文——① 印发/转发类通知（无「特此通知」）；
  ② 以附件收束的通知（国办公开办函〔2019〕61 号）；③ 军报通讯副标题「…的报告」被误判。
- **正例**（仍 warn）：标题含「通知」＋有主送＋无结束语 → 「缺少结束语」。
- **反例**（不 warn）：「请认真贯彻执行。」等价收束 / 「关于印发…的通知」 / 尾部「下载附件：…」。
- **附带**：warn 判定要求"公文形态"（标题自报文种 或 有发文字号），新闻稿不再受骨架约束。

### 6.4 模糊词加出现门槛（❌323 → 115）

- **落点**：`writing_data.py:278` `VAGUE_MIN_COUNT = 3`、`:279` `VAGUE_DENSITY = 1.5`（‰）；
  判定 `writing_hints.py:761` `_vague_hints`。**只约束 `VAGUE_WORDS`，不动 `BAD_WORDS` 契约**。
- **依据**：有关 20/35 篇命中、密度中位 0.21‰、p75 1.79‰；进一步 p75 0.79‰ —— 绝大多数是一次正常使用。
- **正例**：`请有关部门进一步核实，适当调整，及时报送。`（短稿密度天然高）仍报。
- **反例**：3000 字长文里一次「有关要求如下」不报。

### 6.5 重复短语四条收窄（❌375 → 174）

- **落点**：`writing_hints.py:919` `_repeat_hints`、`:891` `_heading_terms`、`:909` `_document_titles`；
  常量 `writing_data.py:311` `PHRASE_REPEAT_MIN_COUNT = 3`、`:318` `PHRASE_EDGE_BLOCK`。
- **四条规则与依据**：
  1. **数字/标点断点不复用**（`:57` `_DOC_TITLE_RE` 同区域的 `_NGRAM_BREAK`）：
     旧实现把非汉字**删掉**再拼 n-gram，条例末尾「（2026年8月30日中华人民共和国国务院令第…号）」
     被拼成「年月日中华人民共和国国务院令第号」——那是格式串碎片，不是重复用语；
  2. **标题主题词豁免**：公文要求主题词全文统一（「政府信息」「伟大长征精神」）；
  3. **《…》文件名豁免**：《政府信息公开条例》《全民健身计划…》反复引用属规范写法；
  4. **首尾虚词豁免**：「和国务院各部门」「了中国共产党」「日中华人民共和国国务院令第」
     是切词事故（`PHRASE_EDGE_BLOCK` 含 的/了/和/在/第…）；
  5. **≥3 次才报**：一段内出现两次在公文里是常态（专名＋回指）。
- **正例**：`安全生产是底线。抓好安全生产是关键。安全生产责任重于泰山。`（3 次）仍报。
- **反例**：`政府信息是核心。政府信息要公开。`（2 次）不报；标题/《》内短语不报。

### 6.6 口语化：引语豁免 + 单字词门槛（❌79 → 37）

- **落点**：`writing_hints.py:802` `_colloquial_hints`（`_QUOTED_TEXT_RE` 在 `:55`）；
  常量 `writing_data.py:220` `COLLOQUIAL_SINGLE_MIN_COUNT = 2`。
- **依据**：「道路一定要搞清楚」是引语；「搞」在 23 篇里 15 篇只出现 1 次（「抓备战、搞训练」「搞腐败」）。
- **正例**：`我们要搞建设，也要搞改革。`（2 次）仍报；`这项工作要抓紧搞定。`（多字词）仍报。
- **反例**：`“道路一定要搞清楚。”`（引号内）不报；`我们要搞建设。`（单次）不报。

### 6.7 标点：阈值提高 + 密度兜底（❌28+26+29 → 9+9+5）

- **落点**：`writing_data.py:194/199/203` 三个 `*_TOTAL = 8`、`:206` `PUNCT_PARA_MAX = 3`、
  `:210` `PUNCT_DENSITY = 5.0`；判定 `writing_hints.py:721` `_punct_hints`（总量 **或** 密度）。
- **依据**：语料 p95 —— 问号 6、省略号 5、感叹号 5；分位统计见 §5 第 9/10/23 行。
- **正例**：短稿 `要行动！要落实！要见效！`（密度 125‰）仍报；`！`×10 仍报。
- **反例**：3000 字长文里分散的 3 个感叹号不报。

### 6.8 层次序号：取消"换父级硬复位"（❌3 跳号 → 0）

- **落点**：`writing_hints.py` `_layer_hints`（删除 `for deeper in range(...)` 复位块）。
- **依据**：国办《关于发展体育赛事激发消费活力的意见》二级序号**跨一级标题连续编号**：
  二、下面（一）～（四），三、下面接着（五）……旧逻辑换父级后把 expected 复位成 1 → （五）被报跳号。
- **正例**：`一、…（一）（二）；二、…（三）` 不再报；真正的跳号（（一）→（三））仍报。
