## 二、评测口径修正（E3 拆分）

- **E3a 可自动替换类误报**（category ∉ `ADVISORY_CATEGORIES`）≤ 0.5 处/万字 → **硬门禁**；
- **E3b 提示类命中**（数字用法/机构沿革/标点规范/表达提示）→ 只报告、不参与门禁；
- JSON 保留 `e3_all` 旧总口径便于跨版本对比；文本输出同时打印两者。

**为什么拆**：只有"可自动替换类"会改用户正文，提示类不会；旧口径把二者混在一起，
既掩盖真实风险（提示类多不等于会改坏），也会让真实语料永远无法过门禁（规范文本本身会有提示类命中）。

## 三、采集工具（开发期，零依赖、零联网构建）

`scripts/fetch_corpus.py`：

- **授权闸门**：受限站点必须有授权文件（`sites` 含该站 + `doc_ref` 非空），否则 exit 3；
- **robots**：`urllib.robotparser` 逐 URL 判定，被禁入 `manifest.skipped`；robots 无法确认时拒绝开跑；
- **限速**：≥1s 且取站点/robots 最大值（人民网 crawl-delay=120s）；
- **抽取**：解析器链 `html.parser → lxml`（stdlib 优先，防 lxml 截断）、多级容器
  `#UCAP-CONTENT → .pages_content → div.trs_editor_view → 最大文本块`、正文 <200 字或 `<p>`=0 记 `manifest.failed`（不静默跳过）；
- **标题碎片合并** `--mend-titles`（默认开）：合并被网页拆开的标题、删除正文重复标题；
- **其它**：`--dry-run`（零写盘）、`--probe`（只看容器命中/失败计数）、`--from-dir`（数据库导出/手工语料导入）、manifest 含 URL/sha256/robots/授权/许可证备注。

配套文档：`doc/corpus/采集合规检查表.md`（站点事实、授权、脱敏、抽取质量、签字栏）、
`doc/corpus/AUTHORIZATION.example.json`（授权模板）、`doc/corpus/README.md`（口径与清洗要求）。

## 四、本批拒绝的一个方案（记录在案）

我最初要求"生成对命中只要横跨词边界就抑制"，审计员实测指出：E2 的 800 样本里
**150/645 条召回正是这个形态**（生成器错形多为"生僻同音字+常用字"，jieba 必切成两词），
一刀切会让 **E2 80.6% → 61.9%**，与"E2 不得下降"冲突。
最终改为两条**零代价**的结构性判据（长度≥3 跨词、长度=2 且末字为列举/语气助词），
既消掉 `屏等`，又保持 E1 100%/E2 80.6% 不变。这条取舍写在这里，避免以后有人"照最初方案再改一遍"。

## 六、仍待你输入的两件事

1. **受限站点授权**：军网/求是/人民网需要 `AUTHORIZATION.json`（模板见 `doc/corpus/AUTHORIZATION.example.json`）。
   没有它，工具只采 gov.cn；提供后一条命令即可扩容语料。
2. **数据库导出（B 路线）**：把知网/万方等授权导出的纯文本放进一个目录，用

## 七、D 批补充：标题碎片合并与语料质量提示

**采集侧 `--mend-titles`（默认开）**：gov.cn 正文容器开头会把标题拆成 2~3 个 `<p>`。
工具只看正文前 6 段，逐段拼接必须是标题前缀、单段 <42 字，**拼回去与标题完全相同才删除**；
否则一字不动。实跑 3 篇：`paras 12→10 / 50→48 / 12→10`，正文以文号开头，标题碎片消失；
下游 `corpus_check` 质量提示 **3→0**、`eval` E3b **3→0**。`--from-dir` 明确不处理（外部文本原样）。

**语料体检侧三条质量提示（不 FAIL）**：
① 标题跨段（两段拼接==标题 / 书名号跨行闭合 / 短片段拼接才成标题；已合并的不告警）；
② 成对符号不配对（《》“”‘’「」『』 开闭数量）；
③ 单段 >1500 汉字。
`gov_cn` 清洗后实测 **0/15** 命中——提示能提前发现"采集把标题拆开"这类假阳性来源。

**目录里的说明文档不再被当语料**：`corpus_check.py` 与 `eval_corrector.py` 共用
`SKIP_CORPUS_NAMES = {README.md, 采集合规检查表.md, AUTHORIZATION.example.json, AUTHORIZATION.json}`
（两边常量有测试断言一致）。真实语料请指向子目录：`--corpus doc/corpus/gov_cn`；
指向顶层 `doc/corpus` 会明确判"外部语料为空"——宁可判空，也不拿说明文档当负样本。

**机构沿革归类**：修复后它**只会提示、绝不写回正文**，因此归 **E3b（提示类）**；
若未来某版本恢复"可自动替换"，必须同时把它移回 E3a（`eval_corrector.py` 的
`E3_ADVISORY_EXTRA` 一行 + 测试会提醒）。
