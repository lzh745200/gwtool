## 五、收口动作（2026-10-25）

1. 本地仓库与远端对齐（`git fetch --tags --force`）；
2. **行尾归一化**：历史 API 直推把 CRLF 原始字节写进远端，导致本地 `git status`
   长期显示 `.bat` 等 14 个文件被修改；按 `.gitattributes` 的 `text`/`eol` 重规范化
   （`--ignore-all-space` 对比：除 `scripts/api_commit.py` 外内容零差异）；
3. **API 推送语义修正**：`scan_local` 对已跟踪文件改取索引 blob
   （`cat-file --batch`），与 `git commit` 的 clean 过滤器一致；目录过滤只看目录段，
   不再误伤 `build_windows.bat` / `build.yml` 等文件名（此前 6 个构建脚本只存在于远端）；
4. 新增回归：`test_scan_local_keeps_build_prefixed_filenames`、
   `test_scan_local_reads_index_content_not_raw_disk`；
5. 工作区干净，语料与授权文件保持 gitignored，远端 `doc/corpus/` 只有 3 个允许文件。
