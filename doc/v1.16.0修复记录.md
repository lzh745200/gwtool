# v1.16.0 修复记录（写作参考库）

> 基线 v1.15.0。本版新增「写作参考库」：把公版/开放授权语料接进写作辅助，
> 支持按「论点/论据/过渡/结尾/模板」检索—对照—仿写；语料包只读、离线。

## 一、功能

| 能力 | 实现 |
|---|---|
| 语料包加载 | 新增 `gwtool/core/material_pack.py`：只读加载目录或 zip（index.json / templates.json / annotations/），坏包给中文错误；`search()` 按句子检索并可按角色过滤，`templates()` 查句式骨架 |
| 检索界面 | 新增 `gwtool/ui/material_dialog.py`：语料包选择（自动发现 Downloads 下 `写作语料库_公版_*`）、关键词、角色筛选、结果列表、来源/规则/置信度预览、复制到剪贴板、插入当前正文（可撤销） |
| 菜单入口 | 工具 → 写作参考库…（`main_window.py`） |
| 语料包 | 655 篇 / **1,198,053 汉字** / **60,801 句结构化标注** / **354 条模板**（模板库.md；程序加载精选 201 条，7.4 MB zip）；不含在仓库内，由构建脚本生成，放在 Downloads 供本机加载 |

## 二、语料来源（合法路径）

- **政府公开文件 35 篇**：中国政府网（gov.cn）公开发布的政策文件；《著作权法》第五条官方文件不适用著作权；采集遵循 robots、3 秒间隔。
- **公版古籍 620 篇**：贾谊新书、论衡、潜夫论、盐铁论、商君书、中论、中说、何博士备论、说苑、读通鉴论、战国策、曾国藩家书；原文公有领域，整理数据 MIT（NiuTrans/Classical-Modern）。
- 排除来源（均有实测原因）：维基文库网络不可达；ctext 有验证码且要求研究授权；国家法律法规数据库 robots 禁止自动化采集；NCPSSD 需登录；Project Gutenberg 无中文语种书目。

## 三、标注与模板

- 逐句规则式标注：角色（论点/论据/过渡/结尾/背景/其他）+ `rule` + `conf`；政府文件与论说文准确率较高，叙事类偏低，模板须人工复核。
- 模板：数字/年份/比例/引文/主体替换为槽位（`{日期}{年份}{比例}{数量}{引文}{主体}`），按「角色 × 文体」统计，附原文例句。

## 六、边界

1. 检索是子串匹配，不做分词/语义检索；
2. 语料包不入库（体积 + 授权说明），需放在 Downloads 或手动选择；
3. 规则标注有误判可能，界面展示 `rule/conf` 供判断，模板以例句为准。
