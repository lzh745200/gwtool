## 4. 已知天花板（不在本轮可解）

1. **词表外错字（OOV）**：基础三层对 OOV 召回 ≈0（E4 1/23 = 4.3%），这是词表法理论限制；要提升必须启用 L4/L5 增强包（默认关闭，因误报 57.6 处/千字量级）；
2. **生成层精度**：39,504 条 conf 0.55 的混淆对在真实语料上 26/26 误报，任何形态守卫都拿 E2 召回换精度（实测：首字=一 杀 5 处但 E2 −11 条），故只能降提示级；
3. **写作提示是启发式**：16 项检查基于阈值/正则，不判断语义；"提示密度 1.32/千字"已是规范公文上的低噪水平，但不能保证零提示；
4. **语料规模**：220 篇真实语料为 E3a 提供了 45.7 万汉字样本，但相对"机关行文"总体仍是小样本；扩到 500 篇真实语料能进一步收紧置信区间（当前 E3a 0 处，置信上界约 0.07 处/万字）。

## 5. 复跑命令

```bash
# 语料体检（真实 220 篇）
python scripts/corpus_check.py doc/corpus/real_all

# 纠错能力（E1/E2 + 真实语料 E3a/E3b/E5）
python scripts/eval_corrector.py --profile base --corpus doc/corpus/real_all \
    --corpus-whitelist doc/corpus/白名单_源文本偏差_220篇.json

# 写作能力（220 篇，输出 JSON+MD，含每条提示触发片段）
python scripts/writing_calibrate.py --corpus doc/corpus/real_all --out artifacts/

# 逐条归因（纠错）
python scripts/e3_triage.py --corpus doc/corpus/real_all --out artifacts/

# CI 档（无需语料）
python scripts/eval_corrector.py --profile base
```

语料指纹（评测输出内）：`real_all = 718eede54ea6fab6`；写作校准指纹见 `doc/写作能力校准_v1.14.md` §10。

## 6. 若要继续提高（按性价比排序）

1. **扩真实语料到 500 篇**（政府公开文本可继续采；军报/求是受授权与栏目存量限制）→ 直接收紧 E3a 置信区间；
2. **人工精标 200–300 条高频生成对**并入 CURATED（448→700+）→ 提升自动替换覆盖，且不牺牲精度；
3. **启用 L4/L5 增强包**（需目标机 onnxruntime + pack）→ 唯一能显著提升 OOV 召回的路径；启用前必须用真实语料复跑 E4/E6；
4. 写作侧：把"提示密度"与"复核耗时"作为产品指标跟踪，而非追求更多检查项。
